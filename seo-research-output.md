# Technical SEO checklist (Next.js specific)

1. **`metadata` API:** Use Next.js 13+ `generateMetadata` to dynamically inject the Titles and Meta Descriptions provided in the page map.
2. **Remove Meta Keywords:** Find `<meta name="keywords" ... />` and delete it. It harms you.
3. **`next/image` Optimization:** Fix the hero image. Do not let it render at `w=3840`. Use the `sizes` attribute (e.g., `sizes="(max-width: 768px) 100vw, 50vw"`). Ensure avatars are small (e.g., `width={150} height={150}`).
4. **Sitemap:** Create `app/sitemap.ts` (or `.js`) to dynamically generate `sitemap.xml` containing `/`, `/about`, `/work`, `/work/roi`, etc., and all blog posts.
5. **Robots.txt:** Create `app/robots.txt` allowing all crawling and pointing to the sitemap.
6. **JSON-LD Schema:** 
    - Inject `Person` schema on the homepage. Include `sameAs` linking to your LinkedIn and GitHub.
    - Inject `BlogPosting` schema on individual blog post pages.
7. **Canonical URLs:** Ensure every page has a canonical URL set in the metadata to prevent duplicate content issues.
8. **Heading Hierarchy:** Ensure exactly one `<h1>` per page. Do not skip heading levels (e.g., jumping from H1 to H3).
9. **Open Graph/Twitter:** Add `openGraph` and `twitter` objects to your `metadata` export for better sharing previews on LinkedIn/Twitter.
