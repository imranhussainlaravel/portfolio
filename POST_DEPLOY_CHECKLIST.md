# Post-Deploy SEO Checklist

- [ ] **Verify Domain:** Verify the domain `imranhussainportfolio.com` in Google Search Console and Bing Webmaster Tools.
- [ ] **Submit Sitemap:** Submit `https://imranhussainportfolio.com/sitemap.xml` to Google Search Console and Bing Webmaster Tools.
- [ ] **Request Indexing:** Run URL Inspection -> Request Indexing for `/`, `/about`, `/work`, each case study, `/blog`, and each post.
- [ ] **Validate JSON-LD:** Validate JSON-LD in Google's Rich Results Test and Schema.org validator.
- [ ] **Check Indexing:** Run `site:imranhussainportfolio.com` in Google search after 1-2 weeks to confirm pages are being indexed correctly.
- [ ] **Update Profiles:** Update LinkedIn, GitHub profile/README, Upwork and other profiles with the site URL and the same name and headline ("Imran Hussain | Laravel & PHP Backend Engineer").
- [ ] **Off-Site SEO:** Start the off-site plan from `seo-research-output.md` (dev.to/Hashnode cross-posts with canonical link back, Laravel communities, directories).
