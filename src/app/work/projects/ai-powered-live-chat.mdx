## Overview

An independent project: a live-chat widget for websites, backed by a Laravel application, with AI
integration handling the first line of customer interaction and capturing leads from those
conversations.

**Stack:** PHP · Laravel · AI Integration

## What I built

The system covers the path from an anonymous website visitor to a qualified lead:

- An embeddable chat widget that visitors interact with directly on the site
- A Laravel backend handling conversation state and message persistence
- AI integration for automated responses to common customer questions
- Lead handling, so conversations that show intent are captured rather than lost when the visitor
  closes the tab

## Outcome

I developed the core backend infrastructure for an AI-powered live-chat solution, utilizing Laravel to broker conversations between anonymous website visitors and the primary logic engine. I owned the complete conversation state management and message persistence layers, ensuring that chat interactions were reliably stored in the database without dropping payloads. I integrated third-party AI APIs to automatically parse and respond to routine customer questions, building a routing mechanism that successfully captures qualified leads when intent is detected. The most significant lesson from this architecture was learning exactly where to draw the boundary for automation; answering routine questions is ideal for AI, but categorizing a conversation as a high-value lead requires the system to hand off state to human operators rather than making silent decisions.

**Key facts:**
- Stack: PHP, Laravel, AI Integration
- Ownership: Backend state management, message persistence, and AI API routing
- Focus: Automated lead capture and conversation tracking
